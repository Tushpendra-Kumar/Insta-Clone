## 📌 Executive Overview

A full-stack social networking application replicating core **Instagram** workflows. Built on the **Node.js + Express + EJS** architecture, featuring user photo posts, dynamic feeds, user profiles, and double-tap like mechanics.

---

## ✨ Key Features & Capabilities

- **Photo Feed Stream:** Infinite scroll style feed displaying posted photography, captions, and author badges.
- **Interactive Like System:** Real-time heart animation and like counter increments.
- **User Profile Architecture:** User account pages displaying individual post grids and bio summaries.
- **Server-Side Rendering (SSR):** High-speed templated rendering powered by EJS views.

---

## 📁 Detailed Project & File Structure

An organized overview of how files and directories are structured in this project:

```
Insta-Clone/
├── app.js                  # Main server entrypoint, middleware mounting & Express setup
├── routes/                 # Route controllers for auth, user feed, posts & profile
├── views/                  # EJS templated views (feed.ejs, profile.ejs, login.ejs)
├── public/                 # Static stylesheets, client scripts & uploaded post media
├── utils/                  # Helper utilities, authentication guards & date formatters
├── bin/                    # Server bootstrap executable
├── package.json            # Node.js dependencies & scripts
└── README.md               # Architecture overview & setup instructions
```
